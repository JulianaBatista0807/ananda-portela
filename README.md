# Landing page — Ananda Portela

Página estática responsiva. O hero desktop segue a referência com container central de 1240px, título em quatro linhas, retrato recortado, círculo rosé, cinco balões e benefícios. A composição usa altura adaptável à viewport até 720px. O layout mobile existente foi mantido e ajustado para o novo wrapper.

## Abrir

Abra `index.html` no navegador. O arquivo `hero-section.html` contém o markup isolado do hero e `hero.css` suas regras específicas; `styles.css` contém os estilos globais e das outras seções.

Os balões ilustram dúvidas genéricas de famílias; não são depoimentos nem conversas reais.

## WhatsApp

Os CTAs usam links com mensagem pré-preenchida. Para direcionar ao número da Ananda, troque `https://wa.me/?text=...` por `https://wa.me/55DDDNUMERO?text=...` nos links do `index.html`.

## Arquivos

- `index.html`: página completa
- `hero-section.html`: markup do hero
- `hero.css`: estilos do hero
- `styles.css`: estilos globais e das demais seções
- `script.js`: menu mobile
